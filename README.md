# Phone Booth Kit

ชุดเครื่องมือของ workshop **Interactive Art + Projection Mapping** กับ Wave Pongruengkiat
Phone Booth Cider Bar & Co. นางเลิ้ง · วันจันทร์ 16 พ.ย. 2026

## ลองเลย

**https://wvweeratouch.github.io/phone-booth-kit/**

กดอนุญาตกล้อง แล้วโบกมือหน้ากล้อง

| ปุ่ม | ทำอะไร |
|---|---|
| D | ดูว่ากล้องเห็นอะไร |
| M | map: ลากมุม 1-4 ไปวางบนพื้นผิวจริง |
| F | เต็มจอ (ย้ายหน้าต่างไปจอ projector ก่อน แล้วค่อย map) |
| Shift+R | ล้างตำแหน่งที่ map ไว้ |
| + media | ในโหมด M ใต้ชื่อแต่ละจอ: ใส่รูปหรือวิดีโอลงจอนั้น (หรือลากไฟล์มาวางบนจอเลยก็ได้) · × media = เอาออก |

ต่อท้ายลิงก์ด้วย `?level=1` ให้กล้องจับมือ หรือ `?level=2` ให้จับคนทั้งตัว

## ทำของตัวเอง

1. โหลด repo นี้ (ปุ่ม **Code → Download ZIP** หรือ `git clone`)
2. ยืนตรงจุดที่ projector ตั้ง แล้วถ่ายรูปพื้นผิวที่จะฉาย
3. ให้ AI ของคุณอ่าน `GUIDE.md` พร้อมรูปนั้น แล้วบอกเป็นประโยคเดียวว่าอยากให้แสงทำอะไร
   ถ้าใช้ Claude Code ให้เปิดในโฟลเดอร์นี้ได้เลย มันจะอ่าน `CLAUDE.md` แล้วไปอ่าน `GUIDE.md` เอง
4. จะได้ `index.html` ไฟล์ใหม่ ดับเบิลคลิกเปิดใน Chrome แล้วกด D, F, M ตามลำดับ

## loop ที่ใช้คิด

```
SENSE  เครื่องต้องรับรู้อะไร
DO     แล้วทำอะไร
FOR    เพื่ออะไร
```

## ข้างในมีอะไร

| ไฟล์ | |
|---|---|
| `sense.js` | กล้องรับรู้ 3 ระดับ · 0 ความเคลื่อนไหว, ปัด (ไม่ใช้ AI, ไม่ต้องใช้เน็ต) · 1 มือ, ท่ามือ · 2 คนทั้งตัว หลายคน, ความเร็ว |
| `map.js` | map ในเบราว์เซอร์ · ทุก element ที่มี `data-surface` คือหน้าจอหนึ่งจอ · ใส่รูปหรือวิดีโอแยกแต่ละจอได้ |
| `index.html` | หน้าตัวอย่าง 2 พื้นผิว คือผนังกับกล่อง |
| `GUIDE.md` | ให้ AI อ่าน |

level 1 กับ 2 ใช้ [MediaPipe](https://ai.google.dev/edge/mediapipe) และต้องต่อเน็ตตอนเปิดครั้งแรก
